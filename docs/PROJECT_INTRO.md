# 百草源花草茶企业展示网站 · 项目介绍

## 一句话

为"百草源"这个虚构的花草茶源头工厂打造的企业展示站——让批发商、经销商和想找代工厂的客户，一进网站就能判断这家工厂靠不靠谱。

## 设计理念

整体风格是"现代中式源头工厂"：干净、可靠、克制。页面大量使用真实的工厂车间、质检和原料摄影，让客户像实地验厂一样建立信任。深绿作品牌主色，米白作底色，金色只在小处点缀。每个页面版式各不相同：首页大图叙事，OEM 页用流程线讲清合作步骤，关于页用时间轴讲公司发展，溯源页用产地关系图讲原料来源——不搞千篇一律的模板页。

## 主要特性

- **六大业务页面**：产品中心（9 款产品）、OEM/ODM 代工、原料溯源、工厂实力、关于我们、联系询盘
- **手机体验好**：产品图手机上看完整不裁切，布局随屏幕自动调整
- **演示安全**：全站对搜索引擎隐藏，页脚明确标注"虚构企业 Demo"
- **询盘表单**：联系页提供完整表单（演示版），提交后有明确提示
- **加载快**：页面为纯静态文件，全球节点加速，打开迅速

## 技术架构（简要）

网站用 Astro 框架构建，发布时一次性编译成纯 HTML 文件，不依赖后台程序，稳定且快。托管在 Cloudflare Pages（全球 CDN），通过域名 demo1.shaojiang61.site 访问。中文字体放在自己服务器上，不依赖外部服务。产品、导航、联系方式等集中存于数据文件，改内容无需动页面结构，维护简单。
